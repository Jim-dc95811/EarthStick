# Acknowledgements and Technology Notes

EarthStick is an independent utility that connects existing public interfaces:

- **Esri ArcGIS Earth** supplies the map, imagery, layers, and local Automation API.
- **Thrustmaster TCA Sidestick Airbus Edition** supplies the physical joystick controls.
- **Microsoft Windows Multimedia joystick services (WinMM)** expose controller state to Python.
- **Python standard library** provides the local program runtime and HTTP communication.

EarthStick and World Gates were conceived, directed and live-tested by **Jim Gaddy**, built with AI coding and documentation help from **OpenAI's ChatGPT** (the original EarthStick, up to 1.0) and **Anthropic's Claude** (every release since 1.1, World Gates and World Gate Maker). See *Human-AI engineering collaboration* in the [README](README.md).
